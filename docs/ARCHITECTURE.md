# Архітектура

```
 ┌────────────────────────────┐
 │  gui-csharp (WPF, .NET 8)  │  інтерфейс, таймери, кнопки
 └──────┬─────────┬─────────┬─┘
  P/Invoke│        │P/Invoke │P/Invoke
 ┌───────▼──┐ ┌────▼─────┐ ┌─▼────────────┐
 │bb_engine │ │ bb_safe  │ │  bb_render   │
 │ C++20    │ │  Rust    │ │ C++/Direct2D │
 └──────────┘ └──────────┘ └──────────────┘
 моніторинг,   захист        плавний графік
 очищення,     процесів,     (HwndHost у WPF)
 живлення      адмін-права
```

## Модулі
| Модуль | DLL | Відповідальність |
|---|---|---|
| `engine-cpp` | `bb_engine.dll` | CPU/RAM, очищення temp, схема живлення, список процесів |
| `safe-rust` | `bb_safe.dll` | Список захищених процесів, безпечне закриття, перевірка адміна |
| `render-d2d` | `bb_render.dll` | Графік навантаження на Direct2D, плавна анімація |
| `gui-csharp` | `BuldogBoost.exe` | Вікно, взаємодія, виклик нативних модулів |

## Правила
- Між модулями — **лише C-інтерфейс** (`extern "C"`, прості структури). Виняток C++ чи паніка Rust не повинні перетинати DLL.
- Структури в `bb_api.h` і C# (`EngineApi.cs`) мають збігатись по розкладу в пам'яті.
- Закривати можна лише те, що не в списку захищених (`safe-rust/src/lib.rs`).
- Кожна дія — зворотна або безпечна; нічого не чіпаємо в реєстрі/службах без відкату.

## Додавання нової функції
1. Оголосити в `engine-cpp/include/bb_api.h`, реалізувати в `engine.cpp`/`platform.cpp`, додати тест.
2. Додати `DllImport` у `gui-csharp/src/Native/EngineApi.cs`.
3. Підключити до кнопки в `MainWindow`.

## Сервіси GUI (`gui-csharp/src/Services`)
| Файл | Призначення |
|---|---|
| `Settings.cs` | JSON-налаштування та ігрові профілі (`%APPDATA%\BuldogBoost`) |
| `AutoStart.cs` | Автозапуск через `HKCU\...\Run` (`--tray` — старт згорнутим) |
| `TrayService.cs` | Іконка й меню в треї |
| `GameWatcher.cs` | Опитування запущених ігор раз на 3 с |
| `BackgroundThrottle.cs` | Приглушення фонових програм (BelowNormal) і відкат; підняття пріоритету гри |
