# Changelog

## [0.2.0]
### Додано
- Рівні Boost: Звичайний / Сильний / Максимум.
- `bb_clean_deep`, `bb_trim_memory`, `bb_flush_dns` у рушії; тести.
- Приглушення фонових програм (BelowNormal) із відкатом; підняття пріоритету гри в ігровому профілі.
- Boost виконується асинхронно — вікно не зависає.

## [0.1.0] — 2026-11-03
### Додано
- C++ Optimization Engine: CPU/RAM, очищення temp, схема живлення, список процесів.
- Rust-модуль безпеки: захищені процеси, безпечне закриття, перевірка адміна.
- Direct2D рендерер плавного графіка навантаження.
- WPF GUI (C#), CMake, скрипт збірки, GitHub Actions.
